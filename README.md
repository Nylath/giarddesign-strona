# GiardDesign

Responsywna strona internetowa przygotowana w ramach zadania rekrutacyjnego na podstawie projektu w Figma.

## Technologie

- React
- Vite
- CSS
- react-masonry-css

## Funkcjonalności

- responsywny układ desktop, tablet i mobile,
- rozwijane menu mobilne,
- wyszukiwarka w navbarze,
- slider zdjęć z automatyczną zmianą i obsługą gestów,
- animowane karty oferty,
- galeria masonry,
- lightbox z nawigacją i licznikiem zdjęć,
- animacje uruchamiane podczas przewijania i najechania kursorem.

## Uruchomienie projektu

```bash
npm install
npm run dev
